# Exploring Quantum Tonality

This folder contains supplementary materials associated with the publication:

> Noll, T., Olives, F. P., González-Fernández, P., & beim Graben, P. (2026). *Exploring Quantum Tonality*. https://doi.org/10.5281/zenodo.18203933

The materials include Mathematica and Max/MSP examples developed in connection with the publication.



## Qte

These materials are included in the `contrib/` section of the **Qte (QuantumTimeEvolution)** repository.
